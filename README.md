# easyScan

Windows 离线扫描工具。支持 JPG、PNG、HEIC/HEIF 和 PDF，纸张外缘识别、透视与弯边校正、光照和细节增强、离线中英文 OCR，以及单张和批量导出。当前版本：1.3.0。

## 使用

解压便携包，保留整个文件夹，双击 `easyScan.exe`。无需安装 .NET。

1. 点击「导入」或拖入图片/PDF。多页 PDF 自动展开为页面队列。
2. 查看自动结果；必要时点击「重新识别」或「调整裁剪」。拖动四角和四个边中点，确认后点击「完成」；「取消」恢复本次调整前的设置。1–4 选择角点，5–8 选择弯边，方向键微调，Shift 加大步长。操作时局部放大镜辅助定位。
3. 调整自然/净白、自动曝光、去阴影、亮度和对比度。「高光与色彩」内可压低高光、增强颜色或校正偏色；「清晰度」内可调整保边降噪和细节增强，默认轻度处理。可将增强应用到全部页面；每页保留独立裁剪和弯边设置。
4. 需要文字时，在「文字识别」中选择当前页、选中页或全部页面，再点击「查看文字」复制或保存 TXT。导入不会自动运行 OCR。识别可取消和重试；扫描参数或原文件变化后需重新识别。
5. 点击「导出」，选择**彩色、灰度或黑白**、导出形式、全部/选中页面。可设置白纸排版及自定义水印，在左侧查看最终效果；保存位置固定显示在窗口底部。勾选「同时导出文字 TXT」可批量保存文字；PDF 可勾选「可搜索文字层」，保持扫描图外观并支持搜索和复制。

彩色适合证书和身份证；灰度保留照片及浅色印章的明暗层次；黑白突出普通文档文字。黑白强度越高，保留的墨迹越多。对于印章较浅的材料，先检查预览。

默认自动按原文件分别导出：图片转 JPG，原 PDF 输出为 PDF。选择「图片」后可以明确选 JPG 或 PNG；选择「PDF」后可按来源分别保存，也可按队列顺序合并。同名文件追加序号，不覆盖原文件。

「结果／原图／对比」互斥切换。滚轮直接围绕鼠标位置缩放，放大后左键拖动，双击或 Home 恢复适应窗口；对比两侧联动。倍率 1.0× 表示适应当前窗口，范围为 0.5×～8×。裁剪期间暂时禁用普通预览缩放。

Ctrl+O 导入，Ctrl+S 导出，Ctrl+Z 撤销，Ctrl+Y 重做，Esc 取消裁剪。队列支持 Ctrl/Shift 多选，Alt+↑/↓ 调整当前页顺序。顶部两个面板按钮可收起文件队列或处理面板。

专业参数旁的问号提供解释：悬停 250 毫秒显示，离开后 350 毫秒关闭；移到其他问号时立即替换旧说明。也可用 Tab 选中问号，按 Enter/空格打开，Esc 关闭。加载时保留图片或占位内容并显示阶段提示，耗时操作使用适度旋转动画；关闭系统动画后使用静态提示。

PDF 统一使用 A4 白纸，默认竖向，可统一改成横向。默认每页一张、12 mm 留白；连续排版则按队列从上到下摆放，间距 6 mm，放不下时自动换页，不拆开单张图片。「页边距与尺寸」可调整留白和内容宽度。按原文件分别导出时，每个来源单独排版；跨文件连续摆放请选择合并 PDF。

水印默认关闭，支持 1～80 字的中英文单行文字、斜向居中、斜向平铺和角落署名。默认灰色、20% 透明度，字号为目标短边的 4%；角落署名保持水平，斜向样式默认 −30°。可调整颜色、透明度、字号、倾斜角度及角落位置。默认只覆盖扫描图，PDF 可切换为覆盖整张白纸。水印仅写入导出副本，不修改原图或工作台结果。

已处理页面使用会话缓存，切页直接复用有效结果；颜色转换复用彩色主预览。缓存预算为 128 MiB 内存、512 MiB 临时磁盘，按最近使用顺序淘汰；源文件版本或参数变化时重新生成相关结果。正常退出清理当前会话，启动时清理无活动锁的残留会话。缓存位于本机 LocalAppData/easyScan/PreviewCache，超出磁盘预算的旧页再次查看时可能需要重新处理。

弯边控制点沿实际纸张外缘调整；勾选「弯边拉直」后用于校正。默认对识别出的纸张轻微内收 0.15%，减少边缘残留背景；裁剪内可调整内收幅度。「整张图」恢复全图并取消内收。取消或切换页面会放弃未确认的裁剪；确认后的整次调整可一次撤销。

自然增强保留纸张底色和印章，偏色校正默认关闭。低光照片先使用自动曝光，局部反光可增加「压低高光」；彩色底纹建议保留自然模式并检查结果。增强参数与导出颜色独立，切回彩色会从彩色处理结果重新生成。

## 边界

- 文件处理在本机完成。便携包不包含参考证书或用户图片。
- PDF 按 300 DPI 渲染后处理，默认输出图片型 PDF；可搜索文字层由离线 OCR 重新生成，不沿用输入 PDF 的原有文字层。
- 快速预览最长边为 1600 像素，超过 1.5× 后按需生成最长边 3200 像素的高清预览；导出和 OCR 仍使用原分辨率校正结果。深度放大及原本失焦的照片仍有清晰度限制。
- 黑白 PNG 保持严格二值，水印透明度使用黑白点阵模拟；JPG 压缩可能产生过渡灰色。中文水印使用 Windows 微软雅黑，便携包不分发字体。
- 自动裁剪比较边缘、前景和背景，并细化纸张轮廓；照片几乎填满画面、内侧装饰框或背景与纸张过于接近时，优先保留全图并标记「待确认」。仍需检查裁剪完整性。
- 弯边校正处理可见外轮廓和轻中度弯曲，不是完整的书页三维展平。折痕、遮挡、已经裁掉的边角、严重模糊，以及完全过曝而丢失的文字无法恢复。
- OCR 面向印刷中英文及数字，置信度较低的行会提示核对；不保证环形印章、手写字或表格结构还原。TXT 按阅读顺序分行，多页 PDF 的 TXT 使用换页符分隔。未检测到文字的空白页仍可正常导出；模型损坏或识别失败会明确报告，不静默生成缺少文字层的成功 PDF。
- 不包含证件正反面排版、摄像头和实体扫描仪接入。不恢复关闭前的处理队列或文字结果；退出前请导出需要的内容。
- 目标系统为 Windows 10/11 x64；Windows N 版本的 Media Foundation 环境尚未验证。

## 开发

需要 .NET 10 SDK（项目默认 10.0.202，允许同主版本后续功能更新）。

```powershell
dotnet restore easyScan.sln
dotnet run --project src/EasyScan.Desktop
dotnet run --project tests/EasyScan.Tests -- artifacts/verification
dotnet run --project tests/EasyScan.Tests -- artifacts/scan-optimization --scan-only
powershell -ExecutionPolicy Bypass -File scripts/Publish.ps1
```

测试命令可在输出目录后追加本地图片路径，用于参考图验收。测试照片与导出结果仅写入被忽略的 `artifacts/`，不会随便携包分发。

模块：`EasyScan.Core` 包含来源/页面模型、解码、检测、处理和导出；`EasyScan.Desktop` 包含 MVVM 工作台、裁剪控件和导出窗口；`EasyScan.Tests` 包含真实图像/PDF 回读、失败/取消、状态及 WPF 渲染检查。

PDFsharp 使用 MIT 版本 **6.2.4**：原计划 6.5.0 已改为 AGPL/商业双许可，默认运行要求许可配置。为替换其传递依赖中的旧版本，直接锁定 `System.Security.Cryptography.Pkcs` 10.0.13；其余核心依赖按计划锁定。完整传递依赖见各项目的 `packages.lock.json`。

OCR 使用 CPU ONNX Runtime 和固定的 PP-OCRv5 mobile 模型，模型及字典约 22.5 MB，位于 `models/ocr/`。运行时不访问网络，不依赖系统 OCR 语言包。缺失时可在开发环境运行 `python scripts/FetchOcrModels.py`，按固定来源及 SHA-256 恢复；发布脚本会先校验模型。PDF 隐藏文字层使用内嵌的轻量字体，不依赖额外安装中文字体。

本次验证记录见 `VERIFICATION.md`。第三方组件、参考实现和模型的许可说明随便携包提供。


## 近年研究方法的扫描优化

扫描增强已加入受 CVPR 2023 彩色背景建模和 ICCV 2023 高分辨率文档处理启发的 CPU 实现，重点保护彩色底纹、纸色和细小文字。黑白输出改为低内存条带计算；离线 OCR 增加有界批处理、超长行分段与方向判断，并修正字符的透视坐标。运行时依赖和 OCR 模型保持不变。
